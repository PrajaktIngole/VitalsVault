# 🏥 Vitals Vault  
**A Web-Based Health Record & Chronic Disease Monitoring System**

---

## 📌 Overview  
Vitals Vault is a full-stack healthcare web application designed to securely manage patient health records and provide early insights into chronic diseases using Machine Learning. The platform enables healthcare professionals to efficiently track patient vitals, access medical history, and make data-driven decisions.

---

## 🚀 Features  
- 📁 Centralized Electronic Health Records (EHR)  
- 🤖 Chronic Disease Prediction using Machine Learning (Random Forest)  
- 📊 Real-time health data visualization dashboard  
- 🔐 Secure authentication & role-based access (Admin/Patient)  
- ⚡ Fast API responses using FastAPI  
- 📈 Patient vitals monitoring & history tracking  
- 🔄 Scalable architecture for future integrations  

---

## 🛠️ Tech Stack  

**Frontend:**  
- React.js  

**Backend:**  
- Node.js  
- FastAPI  

**Machine Learning:**  
- Python (Scikit-learn, Pandas, NumPy)  

**Database:**  
- MongoDB  

---

## 📊 Performance Highlights  
- Handles **100+ patient records**  
- Supports **5+ concurrent users**  
- ML Model Accuracy: **~85\\%–90\\%**  
- API Response Time: **<200ms**  

---

## 🧠 Machine Learning Model  
- Algorithm: **Random Forest Classifier**  
- Purpose: Predict risk of chronic diseases based on patient health parameters  
- Output: Risk prediction with probability score
